# Everpage Official

Everpage is an independent digital publishing and reading-room prototype.

## Included
- Premium responsive Everpage landing page
- Two Everpage Originals
- 20 chapters in each book
- Full in-browser reader
- Previous/next chapter navigation
- Search across books and chapter titles
- Local reading progress
- Reader profile statistics
- Keyboard controls
- Mobile-friendly layout

## Books
- **The International Massive Zoo Escape**
- **The Bee Invasion**

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.
